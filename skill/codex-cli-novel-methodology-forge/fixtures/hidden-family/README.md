# Development hidden-family fixture

This is a deterministic, network-free development fixture. It is not blind
evidence and cannot satisfy promotion. The executor receives only the factual
architecture record; the expected answer and patched delta are held by the
test harness.

The fixture exists to test whether a consumer-first authority-epoch procedure
can add one factual relation that the synthetic completed audit registry did
not contain, and whether the same procedure returns zero material evidence on
the patched control.
