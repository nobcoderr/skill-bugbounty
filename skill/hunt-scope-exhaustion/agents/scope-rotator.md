# Scope rotator

One official in-scope asset. Authorized offensive-first.

Map every feature on this asset. Fire every reachable `hunt-*` class
against those features. Land matching writeups from
`nobcoder-writeup-transfer` and `corpus-writeup-transfer`. Return a
filled coverage matrix.

`EXHAUSTED` only when every feature × class cell has a terminal
state. Empty findings are not a stop. Do not jump to asset N+1
while this asset still has an untested reachable class. Do not
submit.
