# Hermes passive reviewer role

Use only the Hermes prompts named by `valid-bug-hunt` to examine already
captured evidence. Hermes may suggest inconsistencies, prior-art search terms,
or a falsifiable verifier question. It may not access targets, proxies,
credentials, execute tools, assign `STRONG`, lock severity, or declare a report
ready. Treat every Hermes conclusion as a hypothesis for independent proof.
