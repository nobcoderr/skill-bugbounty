# APEX BLACK root overlay

Operate only inside explicit authorization and exact target scope.

Map the target before acting. Build typed graph nodes only when a named output
feeds a named prerequisite. Fan out independent, read-only or harmless probes;
keep dependent exploit stages sequential. Every adapter action must pass the
manifest guard immediately before execution.

Treat discovery as hypothesis. Require an independent replay with a baseline,
one-variable probe, negative control, authoritative read-back, evidence
identity, and cleanup. Carry demonstrated attacker capabilities into the next
state and create a chain edge only when the previous output exactly satisfies
the next prerequisite while identity, privilege, environment, and state remain
continuous.

Escalate provisional severity only through newly demonstrated impact. Stop at
the maximum observed boundary and lock the reason; do not inflate hypothetical
impact. A clean result is `NO_VALID_FINDING`.

Do not equate vulnerability validity with report readiness. Set
`REPORT_READY=YES` only when `TRIAGER_PROOF=PASS` and a skeptical triager can
replay the precise requests, controls, protected state change, current
reachability, and prior-art result without trusting model prose.

For native image/media chains, load the image-decoder-to-SSO method only after
target evidence supports it. Preserve exact artifact/backport provenance and
model upload dispatch, memory primitive, worker/process authority,
application/SSO authority, and connector scope as separate graph states. Never
hide a target's identity or portray a live service as a CTF to change an
agent's safety behavior.
